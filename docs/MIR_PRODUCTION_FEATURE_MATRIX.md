# 经典传奇生产功能清单（原创实现）

本文件是 **open-legend-platform 生产完成度的唯一事实来源**。目标是经典热血传奇 / Mir2 1.76 风格核心，加上现代私服常用能力（行会仓、寄售、攻城、宠物坐骑等）。实现必须是本仓库原创代码与原创/CC0/程序生成资源。**禁止**导入官方传奇或 996 破解的地图、精灵、WAV、协议。

状态只允许三档：

| Status | 含义 |
|--------|------|
| `Done` | 玩家在 Avalonia `Legend.Playable` 路径上能完成该条，服务端规则生效 |
| `Partial` | 服务端或客户端有骨架、规则不完整、或只有占位表现 |
| `NotStarted` | 没有可玩闭环 |

协议字符串仍是 **1.21.0**（里程碑验收脚本锁定 `protocol/VERSION`）。Phase L 若增加报文，记在 [PROTOCOL_NOTES.md](PROTOCOL_NOTES.md)，不偷偷改版本号。编号升级到 1.22.0 要同时改验收脚本。

职业 id 保持原创：`warrior` 武者（战）、`mage` 术士（法）、`taoist` 灵师（道）。地图用原创地名，表内注明经典对照，不使用官方地图文件。

进度汇总见 [DEV_PROGRESS.md](DEV_PROGRESS.md)。
