# Playable Visual Plan — 可玩一屏生产观感

目标：用户进游戏后一眼「像能玩的传奇」，不再是色块 demo。

## 根因（对照用户截图）

- 内置 `Assets/atlas.png` 早期由 `tools/gen_mir_sheet.py` 以 **16×24 逻辑像素色块**绘制。
- 地表菱形同质；树/墙极简；怪种难辨；战斗反馈弱。
- Admin 肖像不可当战斗精灵；世界必须以 MirSheet 动作为准。

## 阶段

### P0 — 默认可玩一屏 ✅
48×64 atlas + AI 切帧 + 阴影/血条/HUD。

### P1 — 八向 / 纸娃娃 / 高度遮挡 ✅ 部分
`dirSlots=8` + `orient_frame`；默认衣/武层；树墙 `DrawSortedWorld` 交错 + 身后半透明。

### P2 — 新手村外密度 / 怪辨识 / 战斗手感 ✅ 部分达标
密地表 + 装饰散布；distinct 主怪；击退/飘字/死亡消散；默认头盔。

### P3 — 手摆聚落 / 怪补帧 / 他人纸娃娃（本刀）✅ 部分达标

1. **手摆点位**：`novice_plain.json` 增加 `clientGround`/`clientDecor`（路网→传送门、广场、水塘花丛、围栏灯灌木石）；`MapLayout` 读取；有手摆时关闭随机装饰散布。
2. **主怪补帧**：史莱姆/野猪/骷髅 walk/attack 程序周期拉大；enrich 用 `animate_mob` + pose 表 attack 底图区分动作。
3. **纸娃娃同步**：协议 `EntitySnapshot` 仅有 `class_id`/`fashion_id`（无衣武头装备外观字段）→ 本地玩家仍按装备三层；**其他玩家**按职业默认衣/武/头 + 时装袍可见。
4. 文档本文件已更新。

### P4 — 仍待
真手绘八向与 WIL 帧密度；协议级装备外观广播；屋顶像素裁剪；装饰碰撞/交互；关卡编辑器可视化摆点。

## 验收
新手村外能认出通往传送门的路与围栏聚落；三主怪 walk/attack 动作更顺；附近其他玩家能看到衣武头/时装层。

诚实差距：手摆仅新手平原；怪补帧仍是切图形变非手绘关键帧；他人装备外观非真实背包同步；非官方 WIL。
