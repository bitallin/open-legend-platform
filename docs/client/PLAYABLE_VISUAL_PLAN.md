# Playable Visual Plan — 可玩一屏生产观感

目标：用户进游戏后一眼「像能玩的传奇」，不再是色块 demo。

## 根因（对照用户截图）

- 内置 `Assets/atlas.png` 早期由 `tools/gen_mir_sheet.py` 以 **16×24 逻辑像素色块**绘制。
- 地表菱形同质；树/墙极简；怪种难辨；战斗反馈弱。
- Admin 肖像不可当战斗精灵；世界必须以 MirSheet 动作为准。

## 阶段

### P0 — 默认可玩一屏 ✅
48×64 atlas + AI 切帧 + 阴影/血条/HUD。

### P1 — 八向 / 纸娃娃 / 高度遮挡 ✅ 部分
`dirSlots=8` + `orient_frame`；默认衣/武层；树墙 `DrawSortedWorld` 交错 + 身后半透明。

### P2 — 新手村外密度 / 怪辨识 / 战斗手感（本刀）✅ 部分达标

1. **地表更密**：地砖增 `grass_c`/`flowers`/水塘等；路网+脏土打散同色菱形；路灯/栏杆/灌木/石堆装饰物交错绘制。
2. **怪种辨识**：`mir-mobs-distinct` 史莱姆/野猪/骷髅独立切帧优先 enrich；程序底图色块与轮廓差异拉大。
3. **战斗手感**：受击击退 nudge；飘字更大更久（击杀粉紫放大）；死亡 `DeathFade` 消散；技能 FX 框更大、寿命更长。
4. **纸娃娃**：默认再叠 `helm_cloth` 头盔层。

### P3 — 仍待
真手绘八向；全槽纸娃娃与他人同步；屋顶像素裁剪；WIL 帧密度；装饰物碰撞/交互。

## 验收
草/路/花/水可见层次；灯/栏/灌木点缀；三主怪一眼可分；挨打有位移+大飘字；死有倒地消散；头上有头盔层。

诚实差距：装饰为程序散布非关卡手摆；怪表仍少向/少帧；击退为客户端表现非服务器位移；纸娃娃头盔仍程序/切图层；非官方 WIL。
