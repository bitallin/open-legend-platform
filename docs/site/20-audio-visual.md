# 20 · 音效与画面

完成度以矩阵 **V-01–V-31、U-01–U-15** 为准。画面「像不像经典客户端」的记录在 `docs/VISUAL_PARITY.md`，本页写资源政策与管线，不复制那份状态表。

## 概述与玩家体验

玩家看到斜 45° 菱形地砖、八方向角色、怪物与 NPC、技能光效和木纹金边 HUD。听到的是程序生成的旋律与音效，而不是从官方客户端抽出的波形。登录有城门与灯火，选角有按职业和性别取的立绘。

这些素材可以继续加精度，但来源只能是原创、CC0 或代码生成。

## 协议 / MsgId

画面几乎不占协议。例外：

| MsgId | 用途 |
|-------|------|
| 2103 `CombatSync` | 决定飘字是伤害、未命中、治疗还是击杀 |
| 3967 `GroundEffectNotify` | 地面火墙等 |
| 3413 `AppearanceSyncNotify` | 换装与时装 |
| 2404 `LevelUpNotify` | 升级光效与音效 |
| 2004 `MoveSync` | 走跑动画的权威位移 |

音量大小不上传服务器。

特效配置表若要同步，用版本包而不是新报文。客户端本地缺特效 id 时用默认闪光，不能因此拒绝战斗。

## 服务端模块与配置

服务端不渲染。与外观有关的数据：

- 物品 `paperdoll`
- 时装 id（[14](14-buff-title-fashion.md)）
- 坐骑与宠物 id（[15](15-pet-hero-mount.md)）
- 地图阻挡，决定墙画在哪（客户端把阻挡格画深色或墙贴图）

图集生成：`tools/gen_mir_sheet.py`，输出 `client/Legend.Playable/Assets/atlas.png` 与 `atlas.json`。HUD 贴图为原创 `ui_chrome.png`（见 VISUAL_PARITY 描述）。

## 客户端表现

Playable 绘制与音频：

- `Ui/WorldCanvas.cs`、`World/IsoProjection.cs`：64×32 菱形砖，点地换回格子
- `Audio/PlayableAudio.cs`、`Audio/ProceduralWav.cs`：程序波形
- 动作帧（VISUAL_PARITY）：站立 8、走 10、跑 8、攻击 10、施法 8、受击 4、死亡 8；五向存储，三向镜像
- 装备层：武器、衣服、头盔；时装盖住衣服和头盔
- 怪物：史莱姆、野猪、骷髅、爬虫、幽灵、绿龙、城门、城墙、旗帜、商人

Unity 音频：`client/unity-mvp/Assets/LegendClient/Scripts/Audio/LegendAudioService.cs`、`LegendProceduralAudio.cs`，说明在 `Assets/LegendClient/Audio/README.md`。

## 登录器相关

登录器可以没有 BGM。若加声音，同样用程序波形或 CC0，不引用游戏图集里的官方替代品。

## 配置热更与脚本钩子

换图集需要发客户端，`reload-pack` 换不了 PNG。规则 id 变了而客户端图集没有对应帧时，用默认帧，并在日志里记一次缺失 id。

`on_level_up` 不负责播声音。声音由客户端收到 `LevelUpNotify` 播放。

## 验收标准

矩阵 V 段与 U 段全部 ID。视觉核对清单：

- 点地与格子一致（斜视角不改变 `MoveReq` 坐标）
- 走、跑、攻、施法、受击、死亡能切换帧
- 换武器与时装能换层
- 飘字与 `CombatSync` 类型一致
- 音量分路与静音能关掉 BGM 而不关掉（或按设置关掉）音效

`VISUAL_PARITY.md` 末尾的精度差距（建筑高度遮挡、纸娃娃分辨率、帧数上限）是素材迭代，不是协议缺口。

## 非目标

- 禁止 WIL、WZL、WMX、官方 WAV、官方 UI 原图进入仓库或运行时加载。
- 不把第三方模型表或技能表现表当成资源管道。
- 不在客户端用闭源文件头做「兼容读取」。

## 扩展路线

未来工作，未进入矩阵。

1. **特效表**。`configs/fx.json`：`fxId`、帧名、挂点（手、地、目标）、音效 id。技能增加可选 `fxId`。客户端缺 id 用默认。这是原创表，不对照字段导入。
2. **环境音分区**。按 `mapId` 选 U-02/U-03/U-04，而不是所有地图一条 BGM。
3. **画质档**。V-31：降低粒子与阴影，不降低格子判定。
4. **CC0 替换**。允许用授权清晰的音效替换程序波形，文件放在 `Assets` 并在 README 记录授权。替换物仍不能是官方客户端提取物。
