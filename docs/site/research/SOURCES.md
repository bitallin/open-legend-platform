# 调研来源

本文件只登记公开资料的**位置与用途**。仓库不保存这些站点的页面正文，也不保存其菜单 JSON。

用途限于：核对「现代私服通常有哪些玩法域」，以便 OLP 用原创协议和原创配置补齐能力。任何实现都以 `docs/site` 与功能矩阵为准。

| 来源 | 用途 | 使用边界 |
|------|------|----------|
| 996 引擎 ShowDoc（`engine-doc.996m2.com`） | 能力域目录。已对照的书目包括 item 34 / 37 / 39 / 40（三端说明书菜单）、item 70（客户端 GUI 规模）、item 30 / 38 / 42（FAQ 与教程索引），以及书目 116 的侧栏（英雄、宠物等级、跨服、拍卖、内功等较新条目）。服务端 Lua 书入口常见于 `#/28/341`，客户端 Lua 书常见于 `#/29/552`，新服务端书常见于 item 88 | 只吸收能力名称。不镜像正文，不把书中命令做成 `legend_api` |
| `https://www.3122.cn/tools/help/996/webhelpindex.htm` | 帮助主题约 600 条的覆盖核对，避免漏掉邮件、攻城、摆摊等大类 | 主题名仅作清单，不抄帮助正文 |
| 公开的 `cfg_game_data` / `cfg_*` 表目录（社区整理，如 tayewan 一类数据说明） | 了解等级、技能、怪物、物品、掉落、商店等**数据种类**是否齐全 | 字段不导入版本包。OLP 用自己的 JSON 形状，见 [18](../18-script-config-hotreload.md) |
| 本仓库 `docs/MIR_PRODUCTION_FEATURE_MATRIX.md` 与 `protocol/` | 已经实现的行为与报文 | 完成度与 MsgId 的事实来源 |

## 不入库的内容

- ShowDoc 页面 HTML、Markdown 转储、整本菜单 JSON。
- 第三方脚本命令手册、面板函数表、元变量表。
- 官方或闭源客户端的地图、WIL/WZL、WAV、UI 原图。

若以后需要更新能力清单，在对应功能页的「扩展路线」加一行玩家可感知的行为，并在本表补来源日期。不要把抓取结果提交进 git。

调研日期：2026-10-30。侧栏增补（书 34 与书 116）已折进 00–22 的扩展路线，见 [编写约定](../conventions.md)。
