# 编写约定

后续补文档或改规格时沿用本页。完成度事实只写在功能矩阵里。

## 一文一域

`00` 到 `22` 每个文件一个 H1。不要把行会和攻城拆成两篇，也不要把支付写进交易篇的正文主体。跨域能力用链接指过去。

每篇固定这些小节，顺序保持一致，方便检索：

1. 概述与玩家体验
2. 协议 / MsgId
3. 服务端模块与配置
4. 客户端表现
5. 登录器相关
6. 配置热更与脚本钩子
7. 验收标准
8. 非目标
9. 扩展路线

「登录器相关」在该域没有登录器职责时写一句话说明即可。

## 状态怎么写

- 矩阵叶子的 Status 列是唯一 Done / Partial / NotStarted 来源。文档里引用 ID（例如 `A-01`），不复制整张状态表。
- 矩阵「说明」列可以引用，用来提醒实现落点。若说明与代码不一致，以代码和 `PROTOCOL_NOTES.md` 为准，并在文档里写清文件路径。
- **扩展路线**里的能力不在矩阵叶子中。它们是未来工作，正文不得写成 Done，也不得在进度分母里加行。真的做完并要计分时，先改矩阵，再改文档。

## 协议

- MsgId 以 `server/Legend.Contracts/ProtocolConstants.cs` 的 `MsgId` 枚举为准，消息字段以 `protocol/legend_protocol.proto` 为准。
- 枚举里没有的报文写 **TBD**，并说明建议的职责。不要编造 MsgId 数字。
- 新 MsgId 按号段追加，并记入 `docs/PROTOCOL_NOTES.md`。在验收脚本仍锁定 `1.21.0` 之前，不单独改 `protocol/VERSION`。升到下一版时要同时改版本文件、`ProtocolConstants`、验收脚本和可玩客户端里的字面量。
- 帧格式：大端 `[Len:4][MsgId:2][Seq:4][Payload]`，Length 不含 10 字节头，Payload 最大 1MB。实现见 `ProtocolConstants.HeaderSize`。

## 命名

- 职业 id：`warrior` 武者、`mage` 术士、`taoist` 灵师。显示名可以对齐经典技能名，id 保持原创。
- 地图、怪物、物品使用 `version-packs` 里的原创 id。经典地名只出现在对照表，不作为资源文件名。
- 脚本全局对象只有 `legend_api`。钩子函数名是 `on_*`。不要引入第三方引擎的命令名、面板函数名或元变量名作为可调用 API。

## 配置

版本包根是 `version-packs/<pack>/manifest.json`。样例包：

- `version-packs/sample-classic/`：当前主样例，协议字符串 1.21.0
- `version-packs/sample-176/`：另一份职业表示例

服务端文本若在调研材料里分成 Setup、String、Command、Exp、Envir、`cfg_*` 等文件，本仓库对应的是 JSON / Lua，见 [18 · 脚本、配置与热更](18-script-config-hotreload.md) 的概念对照表。对照表只说明「哪类数据放哪」，不描述第三方文件格式，也不提供可粘贴的第三方表。

## 资源

画面与声音只使用原创、CC0 或程序生成。禁止提交 WIL、WZL、WMX、官方 WAV，以及从闭源客户端拆出的地图或界面。图集生成入口是 `tools/gen_mir_sheet.py`，产物在 `client/Legend.Playable/Assets/`。

## 扩展路线怎么写

写清玩家能感知的能力、建议落到哪个配置或哪个未来报文（TBD）、以及验收时要补进矩阵的行为。可以列出调研里见过的能力名称，便于产品对齐。不要粘贴第三方说明书正文，不要给出可在第三方引擎里执行的脚本。

本轮已覆盖、但尚未进入矩阵的能力（落点见各篇扩展路线）：

英雄、宠物等级、宝宝强度独立曲线、内功与经络、连击、第四职业及以后、阵营、国家、跨服与跨服攻城、合区脚本变量、通区、大数值、拍卖行与求购、商城多货币、宝石打孔、合成、刀魂、装备投保、首饰盒与生肖、自定义装备位、盾牌、押镖、答题、结婚、高位 Buff、红点、假人、挂机、范围快速拾取、镜像副本、自定义排行榜、静默下载与资源热更、H5 界面、登录器侧工具概念。

邮件、师徒、称号、时装、坐骑、宠物跟随、世界 Boss 血条已经有协议或矩阵条目，写在正文，不重复标成「未开始」。

## 非目标（全站）

全站共同边界：

- 不实现、不声称兼容 996、Crystal、GOM 或任何闭源传奇引擎的协议、脚本命令或资源格式。
- 不在仓库保存第三方说明书全文。
- 不编写外挂、加速器、封包伪造教程。防护只写在 [22](22-security-anti-cheat.md)。
